REA 社交事件发酵时间线 — 本地打开说明
========================================

文件：
  REA事件发酵时间线.html   主页面（纯 HTML/CSS/JS，无构建、无 CDN）
  images/node-01.png … node-10.png   各节点中文示意截图卡
  README.txt               本说明

如何打开：
  1. 用系统文件管理器进入本目录
  2. 双击「REA事件发酵时间线.html」
     或在浏览器地址栏打开该文件的 file:// 路径
  3. 亦可在本目录执行：
       python3 -m http.server 8765
     然后访问 http://127.0.0.1:8765/REA事件发酵时间线.html

课堂使用：
  - 顶部导航可跳转节点；滚动有进度条
  - 点击卡片展开：发生过程 / 结束说明 + 中文示意截图 + 原始链接
  - 「全部展开 / 全部收起」便于投影讲解
